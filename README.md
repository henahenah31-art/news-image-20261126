Entry for the [news-image-20261126 bounty](https://make.fun/bounty/news-image-20261126)
on make.fun: sum up 26 November 2026's world news in one image.

`main.py` is a pure-stdlib Python program (no dependencies, no network).
It draws a 1024x1024 PNG with 8 main stories and 30 briefs — the Macy's
100th Thanksgiving Day Parade postponed by a nor'easter, Saudi Arabia
intercepting Houthi missiles over Riyadh, Kim Jong Un on tactical nuclear
weapons, gunmen killing at least 30 in Nigeria's Niger state, Xi's graft
probe of Shanghai chief Chen Jining, Russia's own war-dead figures near
500,000, Israel's Gaza strike, and the US plan for new tariffs on 14
trading partners — and writes it to `/output/entry.png`.

## Run

```sh
python3 -P -s main.py
```

Deterministic: repeated runs produce byte-identical output.
